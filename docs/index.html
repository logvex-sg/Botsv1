02

What to do with it

full guide ↗

Fleet Manager — Windows

Run the installer

Logvex-Fleet-Manager-v6.0.0-windows-x64-setup.exe. It installs per-user and adds a Start Menu entry.

Launch & choose Host

On first run the app asks whether this machine is the Host or a Worker. Choose Host.

Clear SmartScreen once

The build is self-signed, so Windows may warn the first time. Choose More info → Run anyway.

Fleet Manager — Debian / Ubuntu

Install the .deb

sudo apt install ./Logvex-Fleet-Manager-v6.0.0-linux-x86_64.deb
logvex-fleet-manager

Or run the AppImage

chmod +x Logvex-Fleet-Manager-v6.0.0-linux-x86_64.AppImage
./Logvex-Fleet-Manager-v6.0.0-linux-x86_64.AppImage

No FUSE? Extract and run

Append --appimage-extract-and-run if the AppImage refuses to start.

The Minecraft mods

Install Fabric Loader

For Minecraft 1.21.11.

Add Meteor Client

Put Meteor Client 1.21.11-SNAPSHOT in your mods folder.

Add the jars

logvex-hunter-v6.0.0.jar, plus logvex-worker-v6.0.0.jar on any client the Fleet Manager should drive.

Launch

The addon registers a Logvex Hunter ClickGUI category. Java 21 is required at runtime — a stock 1.21.11 install already uses it.

Connecting a bot to the Fleet Manager. Open Dashboard → Generate pairing code and copy the short code. In the bot client's config/logvex-worker.json, set host, port and pairingCode, then start the client. It appears on the Dashboard — drive it from Workers, Tasks, Commands, Regear and HIVE MODE.

Verify your download

Every release ships SHA256SUMS.txt. Check a file against it:

# Linux
sha256sum -c SHA256SUMS.txt

# Windows PowerShell
Get-FileHash .\Logvex-Fleet-Manager-v6.0.0-windows-x64-setup.exe -Algorithm SHA256
About code signing. The Windows installer is signed with a self-signed certificate generated for this project. That proves the file was not altered after signing, but it is not issued by a public certificate authority, so Windows SmartScreen will still warn until you either trust the certificate or the project buys a CA-issued one. Verify the checksum above for a stronger guarantee.
